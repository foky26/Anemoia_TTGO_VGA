OVERVIEW:
=========
The following files have been modified from the original Anemoia NES emulator 
source code to adapt the emulator for the TTGO VGA32 board. Changes include:

- VGA output configuration (320x240, 6-bit color)
- PS/2 keyboard input integration
- I2S audio setup for built-in DAC
- SD card pin mapping for TTGO VGA32
- Frameskip implementation for performance optimization
- UI adjustments for VGA resolution
- Removal of TFT display dependencies

1. Anemoia_TTGO_Claude_.ino
   ----------------------------------------------------------------------------
   - Main emulator entry point
   - Added TTGO VGA32 specific initialization
   - Configured CPU frequency to 240 MHz
   - Implemented frameskip system (configurable)
   - Set up I2S audio for built-in DAC
   - Added SD card mounting with TTGO pins

================================================================================
SUMMARY OF ADAPTATIONS FOR TTGO VGA32
================================================================================

1. VIDEO OUTPUT:
   - Changed from SPI TFT (ST7789/ILI9341) to VGA output
   - Resolution: 320x240
   - Color depth: 6-bit (64 colors)
   - Uses I2S DMA for VGA signal generation

2. INPUT:
   - Changed from GPIO tactile buttons to PS/2 keyboard
   - Uses fabgl library for PS/2 communication
   - Full NES button mapping on standard keyboard

3. AUDIO:
   - Uses built-in I2S DAC instead of external amplifier
   - Sample rate: 22.05 kHz
   - Mono output (right channel only)

4. STORAGE:
   - SD card pins remapped for TTGO VGA32
   - SPI frequency optimized (20 MHz)

5. PERFORMANCE:
   - CPU frequency: 240 MHz
   - Frameskip: configurable (default: 2)
   - APU on separate core (Core 0)
   - Aggressive compiler optimizations (-O3)

6. MEMORY:
   - No PSRAM required
   - DMA buffers in internal RAM
   - Optimized data structures for ESP32
